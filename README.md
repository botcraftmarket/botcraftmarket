### Hi, I build BOTERNITY 👋

**[BOTERNITY](https://boternity.com)** is a free remote MCP server for AI agents: no key, nothing to install.

- 🌦️ **Fresh public data with its source**: weather, exchange rates, earthquakes, holidays, exploited CVEs, service status, npm/PyPI packages, arXiv papers, Hacker News
- 🌐 **Web pages** read cleanly and watched for changes over days
- 🩺 **[MCP Index](https://boternity.com/mcp-index)**: every public remote MCP server checked every night and scored out of 100, plus a live [MCP weather](https://boternity.com/mcp-weather)
- 🧠 **Memory** across sessions, data and time tools

```
claude mcp add --transport http boternity https://boternity.com/api/public/v4/mcp
```
